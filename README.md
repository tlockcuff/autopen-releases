# Autopen

A multiplayer design canvas where Claude designs alongside you.

On a Mac, open the DMG and drag Autopen to Applications. On Windows, run the installer; it installs for your account only and needs no administrator rights.

Autopen updates itself. It checks for new versions when it starts and every few hours, downloads them in the background, and installs them when it restarts.

The iPhone app is in TestFlight; ask for an invite.
